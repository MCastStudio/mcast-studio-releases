# MCast Studio releases

Official Linux downloads for MCast Studio.

## Install MCast Studio

Go to the [Linux download page](https://mcaststudio.com/download/linux/), choose your distribution and follow the installation steps. It also explains how to set up the optional Virtual Camera component.

For Windows, install MCast Studio from the [Microsoft Store](https://apps.microsoft.com/detail/9P780WH3Q9QC).

## About this repository

This repository hosts release downloads and installation information. It does not contain the MCast Studio application source code.
